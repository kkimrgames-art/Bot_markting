# 🤖 BotMark — بوت الأتمتة لنشر الفيديوهات

بوت تيليجرام مخصص لمهام الأتمتة: جلب الفيديوهات من يوتيوب، معالجتها (قصّ، قلب، إضافة نصوص)، وتوليد ونشر الفيديوهات تلقائياً على قنوات يوتيوب — مع أنظمة حماية ذاتية (إعادة تشغيل تلقائية، إشعارات، مراقبة موارد).

> 🚀 **المثبّت**: يُثبَّت مثل أي برنامج عادي — أمر واحد، ثم `botmark` يشتغل من أي طرفية في أي وقت.
> لا تحتاج لفتح الشفرة أو التعامل مع ملفات المشروع إطلاقاً.

---

## ✨ المميزات

| الميزة | التفاصيل |
|---|---|
| **تثبيت مثل البرامج العادية** | أمر واحد فقط، والبرنامج يُثبَّت في مجلد خاص به (`~/.botmark-app`) |
| **أمر واحد للتشغيل** | `botmark` من أي مجلد وفي أي وقت |
| **اختيار ملف الإعدادات مرة واحدة** | أول تشغيل فقط: يطلب منك اختيار ملف `.env` ثم يحفظه ويتذكره |
| **يعمل كتطبيق** | تشغيل أمامي (مع السجل مباشرة) أو في الخلفية (`botmark start -b`) |
| **فحص جاهزية** | `botmark doctor` يتأكد من Python وffmpeg والمتطلبات قبل التشغيل |
| **سجل كامل** | كل ما يطبعه البوت يُحفظ في `~/.botmark/logs/bot.log` |

## 📥 التثبيت (مثل أي برنامج)

### المتطلبات المسبقة
- **Python 3.9+** مثبت على جهازك (من [python.org](https://www.python.org/downloads/))
- اتصال بالإنترنت (لتنزيل المتطلبات أول مرة)

### الطريقة الأسرع — أمر واحد (Linux / macOS)

افتح الطرفية (Terminal) والصق هذا السطر واضغط Enter:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/kkimrgames-art/Bot_markting/main/install.sh)"
```

المثبّت يقوم بكل شيء تلقائياً:
1. يحمّل البرنامج إلى `~/.botmark-app`
2. يثبّت المتطلبات في بيئة معزولة
3. يجعل أمر `botmark` متاحاً من أي مكان (ويضيف المسار إلى PATH تلقائياً)

### الطريقة الأسرع على Windows — أمر واحد (PowerShell)

> ⚠️ ملاحظة: `bash` غير موجود في Windows — أمر Linux أعلاه للـ Linux/macOS فقط.

افتح **PowerShell** (قائمة ابدأ → اكتب `PowerShell` → افتحه) والصق هذا السطر واضغط Enter:

```powershell
irm https://raw.githubusercontent.com/kkimrgames-art/Bot_markting/main/install.ps1 | iex
```

المثبّت يقوم بكل شيء تلقائياً:
1. يحمّل البرنامج إلى `%USERPROFILE%\.botmark-app`
2. يثبّت المتطلبات في بيئة معزولة
3. يضيف المسار إلى PATH تلقائياً — ثم `botmark` يعمل من أي نافذة جديدة

### التحميل اليدوي (اختياري)

- **Linux / macOS:** نزّل المشروع من GitHub (`Code` → `Download ZIP`) وفك الضغط، ثم داخل المجلد نفّذ `bash install.sh`
- **Windows:** نزّل `install.bat` من GitHub وشغّله بنقرة مزدوجة (المثبّت يضيف المسار إلى PATH تلقائياً)

## 🚀 التشغيل (أول مرة)

```bash
$ botmark
```

في **أول تشغيل** فقط، سيعرض عليك اختيار ملف الإعدادات `.env`:

```
📂 وجدنا ملفات إعدادات جاهزة — اختر واحداً:
   1) /path/to/project/.env
   2) /home/user/bot-backup.env
   p) لصق المسار الكامل لملف .env آخر
   c) إنشاء ملف .env جديد من القالب
   q) إلغاء
```

اختر ملفك، وسيتحقق BotMark منه فوراً:

```
✅ TELEGRAM_BOT_TOKEN = 123456:••••••••xyz
✅ SUPABASE_URL = https://xxxx.supabase.co
✅ SUPABASE_KEY = eyJhbGci••••••••x3d
⚠️  مفاتيح موصى بها غير موجودة: GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET
```

ثم يُشغَّل البوت فوراً. من المرة الثانية، يكفي:
```bash
$ botmark
```

### ملف `.env` — بيانات الاتصال
| المفتاح | مطلوب؟ | الوصف |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | ✅ أساسي | توكن البوت من @BotFather |
| `SUPABASE_URL` | ✅ أساسي | رابط قاعدة البيانات |
| `SUPABASE_KEY` | ✅ أساسي | مفتاح قاعدة البيانات |
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` | ⭐ موصى به | OAuth يوتيوب للرفع |
| `GOOGLE_REDIRECT_URI` | ⭐ موصى به | `http://localhost:8080/` |
| `YTDLP_COOKIES_B64` / `YTDLP_COOKIES_PATH` | ⭐ موصى به | كوكيز يوتيوب لنجاح التنزيل |
| `TELEGRAM_ALLOWED_USER_IDS` | اختياري | يُضاف تلقائياً عند أول رسالة |

## 🧭 الأوامر

| الأمر | الوظيفة |
|---|---|
| `botmark` | تشغيل البوت (الواجهة الأمامية، Ctrl+C للإيقاف) |
| `botmark start -b` | تشغيل البوت في الخلفية |
| `botmark setup` | اختيار ملف `.env` / مجلد مشروع آخر |
| `botmark doctor` | فحص جاهزية الجهاز (بايثون، ffmpeg، المتطلبات، ملف الإعدادات) |
| `botmark env` | عرض ملخص مفاتيح ملف الإعدادات الحالي |
| `botmark status` | هل البوت يعمل في الخلفية؟ |
| `botmark stop` | إيقاف البوت في الخلفية |
| `botmark logs` | عرض آخر سجلات البوت (`--tail 200` لعدد أكبر) |
| `botmark version` | رقم الإصدار |

## ⚙️ كيف يعمل البوت محلياً؟

نفس منطق النشر على السيرفر تماماً، لكن على جهازك:
- `botmark` يقرأ ملف `.env` الذي اخترته ويحقنه في بيئة التشغيل.
- يطلق `main.py` — نقطة الدخول الموحّدة التي تشغّل **كل شيء**:
  - 🤖 بوت تيليجرام (Polling تلقائي — لا يحتاج Webhook محلياً)
  - 🔄 حلقة الجلب التلقائي للفيديوهات (Auto-Fetch)
  - 👷 عامل معالجة المهام (Worker)
  - 🩺 خادم صحة محلي على المنفذ `8080` (`http://localhost:8080/health`) لاستقبال OAuth
  - 🛡️ إعادة تشغيل تلقائية لأي مهمة تتعطل + إشعارات للمسؤول

## ❓ أسئلة شائعة

**أين يُثبَّت البرنامج؟**
في مجلد `~/.botmark-app` — لا تحتاج لفتحه أبداً، تتعامل معه عبر أمر `botmark` فقط.

**أريد تغيير ملف الإعدادات؟**
```bash
botmark setup
```

**البوت يعمل على سيرفر — هل سأتعارض معه؟**
لا. البوت محمي بقفل نسخة واحدة على نفس الجهاز، وكل جهاز له إعداداته الخاصة.

**البيانات أين تُحفظ؟**
- الإعدادات: `~/.botmark/config.json`
- السجلات: `~/.botmark/logs/bot.log`
- بيانات البوت المحلية (قنوات، مصادر، حالات): مجلدات `.data/` و`outputs/` داخل مجلد التطبيق.

**كيف أتوقف عن النسخة التي في الخلفية؟**
```bash
botmark stop
```
